## 🌍 English

### Key Features
* **Rune System:** Includes Keystones and minor runes inspired by League of Legends.
* **Custom UI:** Dedicated interface for rune selection and detailed descriptions.
* **Immersive Experience:** Includes custom visual effects and SFX feedback when runes proc.
* **Upcoming*:** Bosses, weapons, etc.

### Notes
* **Compatibility:** Full support for both Single-player and Multiplayer(maybe).
* **Balancing:** Stats and mechanics are subject to change for better gameplay balance.
* **IT'S OP RIGHT NOW**

## 🏮 中文介绍

### 核心功能
* **符文系统：** 深度参考《英雄联盟》设计的基石符文与普通符文组合。
* **内置界面：** 拥有自定义的符文选择面板，包含详细的中文说明。
* **反馈效果：** 符文触发时带有专属的视觉特效与音效反馈。
* **大饼🫓：** Boss，武器等。

### 说明事项
* **模式支持：** 完美适配单人模式与多人联机（或许吧）。
* **持续更新：** 为了游戏体验，数值可能会在后续版本中持续调整。
